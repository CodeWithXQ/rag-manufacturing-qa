# 工业机器人急停误触发故障

## 一、故障现象
机器人在正常运行时突然急停，但实际无人员触发急停按钮，重新复位后仍可能再次误触发，影响生产节拍。

## 二、常见原因
1. 急停回路接线松动、触点氧化接触不良
2. 安全门/光栅信号受干扰误动作
3. 安全继电器故障或参数设置不当
4. 急停回路电缆破损、屏蔽不良

## 三、排查步骤
1. 查看控制器报警记录，定位是哪个急停回路触发
2. 用万用表分段测量急停回路通断与接触电阻
3. 检查安全门、光栅是否受震动或干扰误动作
4. 检查急停回路电缆有无破损、屏蔽接地情况

## 四、维修处理
1. 紧固急停回路接线端子，更换氧化触点
2. 调整光栅灵敏度或屏蔽干扰源
3. 更换故障安全继电器或重新设置参数
4. 更换破损电缆，做好屏蔽接地

## 五、预防措施
定期检查急停回路接线与安全器件，安全回路走线与动力线分离，做好屏蔽。
