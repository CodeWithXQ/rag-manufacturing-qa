# 编码器信号抖动故障

## 一、故障现象
编码器输出脉冲信号抖动、丢脉冲，位置反馈不稳，电机速度波动，定位精度下降。

## 二、常见原因
1. 编码器信号线屏蔽不良受干扰
2. 编码器与轴的联轴器松动
3. 编码器供电纹波过大
4. 信号线接触不良或老化

## 三、排查步骤
1. 用示波器观察编码器脉冲波形是否抖动
2. 检查信号线屏蔽与接地
3. 检查编码器联轴器是否松动
4. 测量编码器供电纹波

## 四、维修处理
1. 更换屏蔽线、正确接地
2. 紧固联轴器
3. 加滤波或更换供电
4. 更换老化信号线

## 五、预防措施
定期检查编码器联轴器与信号线，做好屏蔽接地，保证供电稳定。
