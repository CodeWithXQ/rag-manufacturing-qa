# 注塑机顶出系统故障

## 一、故障现象
制品脱模时顶出动作无力、卡滞或无法顶出，顶出杆运动不平稳，制品粘模难以取出，顶出板动作歪斜。

## 二、常见原因
1. 顶出销缺润滑、磨损或对齐不良，导致顶出卡滞
2. 顶出油缸压力不足，推力不够
3. 模具开模行程受限，顶出空间不足
4. 顶出板不水平，模具底座支撑柱损坏
5. 顶出油缸密封件老化泄漏

## 三、排查步骤
1. 检查顶出销的润滑与对齐情况，观察有无弯曲、卡滞
2. 观察顶出动作是否平稳，测量顶出力是否足够
3. 检查模具开模行程是否满足顶出需要
4. 检查顶出板是否水平，底座支撑柱有无损坏
5. 检查顶出油缸密封有无渗漏

## 四、维修处理
1. 定期润滑顶出销，校正或更换弯曲、磨损的顶出销
2. 评估顶出力需求，必要时增大顶出油缸规格
3. 调整开模行程，保证足够顶出空间
4. 更换损坏的模具底座支撑柱，校正顶出板水平
5. 更换顶出油缸老化的密封件

## 五、预防措施
定期润滑并检查顶出销对齐情况，保持顶出油缸密封良好，避免开模行程不足导致的顶出卡滞。
