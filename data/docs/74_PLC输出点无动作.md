# PLC 输出点无动作故障

## 一、故障现象
PLC 程序运行正常、输入信号到位，但对应输出点不动作，指示灯不亮或灯亮但外部执行元件（接触器、电磁阀）不吸合。

## 二、常见原因
1. 输出点硬件损坏（继电器触点烧蚀、晶体管击穿）
2. 输出点外部电源缺失或公共端（COM）接线松动
3. 程序逻辑未接通该输出，或存在互锁、复位条件
4. 输出端子接线松动、断路
5. 输出点被强制（强制 OFF）或看门狗复位

## 三、排查步骤
1. 观察输出点指示灯状态，区分是"灯不亮"还是"灯亮但无动作"
2. 通过编程软件监控输出点状态，判断是程序问题还是硬件问题
3. 检查输出公共端电源与接线
4. 测量输出端子电压，判断输出点是否真正闭合
5. 检查程序中的互锁、强制、复位逻辑

## 四、维修处理
1. 更换损坏的输出继电器或输出模块
2. 恢复输出外部电源，紧固公共端接线
3. 修正程序逻辑，解除错误的互锁或强制状态
4. 紧固输出端子接线，排除断路
5. 复位看门狗，重新下载程序

## 五、预防措施
输出点负载电流不应超过额定值，感性负载加装续流二极管，定期检查输出端子紧固，避免强制状态遗留。
