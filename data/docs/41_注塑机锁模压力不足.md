# 注塑机锁模压力不足故障

## 一、故障现象
注塑机锁模压力达不到设定值，合模不紧，制品出现飞边，锁模动作缓慢无力。

## 二、常见原因
1. 锁模液压系统压力不足
2. 锁模油缸密封件磨损内泄
3. 锁模比例阀或溢流阀故障
4. 液压泵供油不足

## 三、排查步骤
1. 观察锁模压力表读数与设定值对比
2. 检查锁模油缸有无内泄（测压法）
3. 检查锁模比例阀、溢流阀设定
4. 检测液压泵供油压力与流量

## 四、维修处理
1. 重新设定或维修锁模液压阀
2. 更换锁模油缸密封件
3. 清洗或更换比例阀、溢流阀
4. 检修液压泵

## 五、预防措施
定期检测锁模压力与油缸密封，保持液压油清洁，按周期更换密封件。
