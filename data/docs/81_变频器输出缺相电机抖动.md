# 变频器输出缺相电机抖动故障

## 一、故障现象
变频器报输出缺相故障（面板显示 LF、SPo 等代码），电机运转抖动、无力、发热，转速不稳，严重时电机停转。

## 二、常见原因
1. 输入电源缺相或三相不平衡
2. 变频器输出 UVW 接线松动或损坏
3. 输出端子到电机的线缆断线
4. 电机绕组断相或阻抗异常
5. 变频器内部逆变模块输出异常

## 三、排查步骤
1. 检查输入电源是否缺相、三相是否平衡
2. 紧固变频器输出端子螺钉，检查接线
3. 测量输出线缆通断，排除断线
4. 测量电机三相绕组电阻，判断是否断相
5. 用示波器或万用表检查变频器 UVW 三相输出

## 四、维修处理
1. 恢复输入三相电源，排除缺相
2. 重新紧固输出端子螺钉
3. 更换断线或损坏的输出线缆
4. 修复或更换断相的电机
5. 更换输出异常的变频器逆变模块

## 五、预防措施
定期检查输入输出接线紧固，监测三相平衡，避免电机长期缺相运行，选用合格线缆。
