# 电机空载电流过大故障

## 一、故障现象
电机空载运行时电流明显偏大、超过额定空载电流，电机温升加快，三相电流不平衡，运行效率下降。

## 二、常见原因
1. 电源电压过高或三相不平衡
2. 定子绕组匝间短路
3. 转子与定子气隙不均匀，发生扫膛
4. 轴承损坏、机械摩擦阻力增大
5. 电机接线错误（如 △ 接误接为 Y 接）

## 三、排查步骤
1. 测量空载电流并与额定值对比
2. 测量电源电压与三相平衡情况
3. 测量三相空载电流是否平衡，判断有无匝间短路
4. 检查转子与定子气隙是否均匀，有无扫膛
5. 检查轴承与机械摩擦情况

## 四、维修处理
1. 恢复电源电压至正常范围，排除三相不平衡
2. 修复匝间短路的绕组
3. 调整转子与定子气隙，消除扫膛
4. 更换损坏的轴承，减小机械摩擦
5. 纠正错误的接线方式

## 五、预防措施
定期测量空载电流并记录，监测电压三相平衡，保持轴承良好，避免电机扫膛和接线错误。
