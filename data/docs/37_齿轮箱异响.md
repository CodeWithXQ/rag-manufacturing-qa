# 齿轮箱异响故障

## 一、故障现象
齿轮箱运转时发出周期性敲击或摩擦异响，异响频率与齿轮啮合频率相关，箱体振动增大。

## 二、常见原因
1. 齿轮齿面磨损、点蚀或断齿
2. 轴承磨损导致啮合间隙变化
3. 润滑油不足或污染，润滑不良
4. 齿轮安装同轴度偏差

## 三、排查步骤
1. 用振动分析仪测啮合频率与边频带
2. 检查润滑油位、油质与油温
3. 开箱检查齿面磨损与点蚀情况
4. 检查齿轮轴同轴度

## 四、维修处理
1. 更换磨损或断齿的齿轮
2. 更换轴承、恢复啮合间隙
3. 更换润滑油、清洗箱体
4. 重新校正齿轮安装同轴度

## 五、预防措施
定期振动监测与油液分析，按周期换油，避免冲击载荷与超载运行。
