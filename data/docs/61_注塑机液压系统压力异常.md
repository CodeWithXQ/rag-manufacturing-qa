# 注塑机液压系统压力异常故障

## 一、故障现象
液压系统压力表读数偏低或偏高，执行机构动作无力或冲击过大，压力波动明显，无法稳定在工艺要求范围内。

## 二、常见原因
1. 压力不足：溢流阀阀芯卡滞或弹簧疲劳、油泵磨损内泄、密封件（油缸活塞密封、管路接头）老化泄漏、压力传感器故障
2. 压力过高：溢流阀设定值过高、电磁阀换向阀阀芯未复位堵塞油路
3. 压力波动：油液中混入空气、油泵吸油不畅

## 三、排查步骤
1. 观察压力表读数，区分是整体偏低、偏高还是波动
2. 用压力表检测油泵出口压力，判断油泵是否磨损
3. 检查溢流阀阀芯是否卡滞、弹簧是否疲劳
4. 检查各密封件与管路接头有无泄漏
5. 手动推动电磁阀阀芯，判断换向阀是否灵活复位

## 四、维修处理
1. 拆洗溢流阀，更换疲劳的弹簧，重新校准设定值
2. 检修或更换磨损的油泵
3. 更换老化的油缸密封件与管路接头密封
4. 校准或更换压力传感器
5. 清洗或更换未复位的换向阀阀芯
6. 排除油路空气，检查吸油管路密封

## 五、预防措施
定期检测液压系统压力并记录，保持油液清洁，及时更换密封件，避免压力长期超调运行。
