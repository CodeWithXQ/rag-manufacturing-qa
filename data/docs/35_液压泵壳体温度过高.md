# 液压泵壳体温度过高故障

## 一、故障现象
液压泵壳体温度异常升高，油液局部过热变质，泵效率下降，伴随异常噪声。

## 二、常见原因
1. 泵内泄过大，高压油回泄产生热量
2. 吸油不畅，产生空穴气蚀
3. 泵轴与电机轴不同心，机械摩擦
4. 系统长时间高压溢流

## 三、排查步骤
1. 用红外测温仪测泵壳体各部位温度
2. 检查吸油滤网是否堵塞、油位是否正常
3. 检测泵轴与电机轴同轴度
4. 观察系统是否长时间高压溢流

## 四、维修处理
1. 检修泵内泄（更换配油盘、柱塞）
2. 清洗吸油滤网、补足油位
3. 重新校正泵与电机同轴度
4. 优化系统减少高压溢流时间

## 五、预防措施
定期测泵壳体温度与油液清洁度，保证吸油通畅，监控系统压力。
