# PLC 通讯故障

## 一、故障现象
PLC 与上位机、触摸屏（HMI）或其它 PLC 之间通讯中断，数据无法读写，监控界面显示通讯超时或通讯报警。

## 二、常见原因
1. 通讯参数设置不一致（波特率、站号、数据格式、协议）
2. 通讯线缆损坏、接头松动、接线错误
3. 通讯接口模块损坏
4. 通讯距离过长或线路受电磁干扰
5. 上位机通讯程序或驱动异常

## 三、排查步骤
1. 核对 PLC 与上位机的通讯参数是否一致
2. 检查通讯线缆与接头，确认接线正确、无松动
3. 用万用表测量通讯线路通断，排除断线
4. 检查通讯接口指示灯状态，判断数据收发是否正常
5. 检查线路周围有无变频器、大功率设备等干扰源

## 四、维修处理
1. 统一通讯参数（波特率、站号、数据格式）
2. 更换损坏的通讯线缆，重新压接或紧固接头
3. 更换损坏的通讯接口模块
4. 缩短通讯距离，通讯线加装屏蔽层并可靠接地
5. 排除干扰源或加装隔离器

## 五、预防措施
通讯线采用屏蔽双绞线并远离动力线，保持通讯参数记录一致，定期检查通讯接头，避免线路受潮氧化。
