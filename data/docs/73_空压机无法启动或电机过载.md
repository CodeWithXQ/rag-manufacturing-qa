# 空压机无法启动或电机过载故障

## 一、故障现象
按下启动按钮后空压机不启动或启动即跳闸，电机过载保护动作，无法正常加载运行，或启动时电流异常偏大。

## 二、常见原因
1. 电源故障：缺相、电压过低、电源线接触不良
2. 接触器、启动器触点烧蚀或线圈损坏
3. 电机绕组故障、轴承损坏或绝缘下降
4. 主机卡死、轴承抱死，负载过大
5. 压力开关或控制系统未复位、卸载阀故障导致带载启动

## 三、排查步骤
1. 检查三相电源电压与接线是否正常，有无缺相
2. 检查接触器、启动器触点与线圈
3. 测量电机绕组电阻与绝缘，判断是否烧坏
4. 手动盘动主机，判断是否卡死或阻力过大
5. 检查压力开关状态，确认是否带载启动

## 四、维修处理
1. 恢复三相电源，紧固接线，排除缺相
2. 更换烧蚀的接触器触点或损坏的线圈
3. 重绕或更换电机，更换损坏轴承
4. 检修主机，解除卡滞或轴承抱死
5. 复位控制系统，修复卸载阀，避免带载启动

## 五、预防措施
定期检查电源与电气元件，监测电机电流，保持主机润滑，避免长期停用后直接带载启动。
