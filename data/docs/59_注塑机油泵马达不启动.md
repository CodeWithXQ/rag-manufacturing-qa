# 注塑机油泵马达不启动故障

## 一、故障现象
按下启动按钮后，油泵电动机不转动，整机无法建立液压压力；或马达发出异常嗡嗡声但不旋转，随即跳闸。

## 二、常见原因
1. 保险丝熔断或松脱
2. 三相电源缺相、电压异常
3. 启动按钮、交流接触器线路松脱
4. 热继电器动作（过载保护）
5. 油泵卡死导致马达堵转
6. 马达绕组烧坏

## 三、排查步骤
1. 用万用表检查三相电源电压是否正常，有无缺相
2. 检查保险丝是否熔断或松脱
3. 检查启动按钮、接触器触点与接线是否良好
4. 检查热继电器是否动作，判断是否过载
5. 手动盘动马达与油泵，判断是否卡死
6. 测量马达绕组电阻，判断是否烧坏

## 四、维修处理
1. 更换熔断的保险丝，重新紧固
2. 恢复三相电源，排除缺相
3. 紧固按钮、接触器接线，更换烧蚀的触点
4. 查明过载原因后复位热继电器
5. 解除油泵卡滞，必要时修理油泵
6. 按原规格重绕或更换烧坏的马达，并查明原因（断相、过载、接触不良）

## 五、预防措施
定期检查电源线路与接触器触点，监测三相电压平衡，避免油泵长期过载或缺相运行，及时更换老化接触器。
