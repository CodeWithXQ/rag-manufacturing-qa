# 水泵异响故障

## 一、故障现象
水泵运行发出异常噪声（汽蚀声、摩擦声、撞击声），出口压力波动，流量不稳。

## 二、常见原因
1. 泵汽蚀（吸入口压力过低）
2. 叶轮与泵壳碰擦
3. 轴承磨损或润滑不良
4. 泵内进入异物

## 三、排查步骤
1. 听噪声特征，判断汽蚀还是机械摩擦
2. 检查吸入口过滤器是否堵塞、液位是否过低
3. 检查叶轮与泵壳间隙、轴承状态
4. 拆检泵内有无异物

## 四、维修处理
1. 提高吸入口压力、疏通吸入管路
2. 调整叶轮与泵壳间隙
3. 更换磨损轴承、恢复润滑
4. 清除泵内异物

## 五、预防措施
保证吸入口压力与液位，定期检查过滤器与轴承，避免泵空转。
