# 三相异步电机过热故障

## 一、故障现象
电机运行时外壳温升明显偏高，超过允许温升，绝缘老化加速，严重时触发热继电器跳闸或烧毁绕组。

## 二、常见原因
1. 长期过载运行，负载电流超过额定值
2. 三相电压不平衡或缺相运行
3. 风扇损坏、风道堵塞，通风散热不良
4. 轴承损坏或装配不良，机械摩擦生热

## 三、排查步骤
1. 用钳形表测量三相电流，判断是否过载或三相不平衡
2. 测量三相电源电压，检查有无缺相
3. 检查风扇是否转动、风道是否积灰堵塞
4. 手摸轴承部位温度，听轴承运转声音

## 四、维修处理
1. 降低负载或更换更大功率电机
2. 修复电源缺相/不平衡（检查接触器触点、熔断器）
3. 清理风道、更换损坏风扇
4. 更换损坏轴承，重新校正联轴器同轴度

## 五、预防措施
定期测电流、测温升，加装电机综合保护器，保持通风良好，按周期润滑轴承。
