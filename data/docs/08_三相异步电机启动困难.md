# 三相异步电机启动困难故障

## 一、故障现象
电机通电后无法启动、启动缓慢或发出嗡嗡声但不转，伴随电流大、发热快，甚至保险丝熔断。

## 二、常见原因
1. 电源缺相或电压过低
2. 绕组匝间短路或断路
3. 机械负载过重或卡死
4. 降压启动装置（星三角/软启动）切换故障

## 三、排查步骤
1. 测量三相电源电压，确认是否缺相、电压是否正常
2. 用万用表/兆欧表测绕组电阻与绝缘，判断短路、断路
3. 盘车检查转子能否自由转动，判断机械卡阻
4. 检查启动装置切换时序与触点接触

## 四、维修处理
1. 修复电源缺相（检查断路器、接触器、接线端子）
2. 绕组短路/断路需重绕或更换电机
3. 排除机械卡阻，降低启动负载
4. 检修或更换降压启动装置

## 五、预防措施
启动前检查电源与盘车，定期测绝缘电阻，避免带载启动，做好启动装置点检。
