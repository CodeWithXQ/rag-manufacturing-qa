# 空压机高温跳机故障

## 一、故障现象
空压机运行时排气温度或油温持续升高，超过设定保护值后自动跳机停机，面板显示高温报警，无法连续运行。

## 二、常见原因
1. 散热系统不良：风冷机型散热翅片积灰油污、风道堵塞；水冷机型冷却器结垢、水路堵塞；冷却风扇故障
2. 油路系统问题：润滑油油位过低、油品老化劣化、油过滤器堵塞、断油阀故障
3. 温控阀故障，阀芯卡滞，润滑油始终走小循环不经过冷却器
4. 环境温度过高、机房通风不良
5. 温度传感器故障误报

## 三、排查步骤
1. 检查散热系统：吹扫风冷翅片，检查水冷冷却器与冷却水循环
2. 检查润滑油油位（正常约在油镜 1/2 处）与油质
3. 检查油过滤器是否堵塞，加载瞬间油压变化
4. 拆检温控阀，判断阀芯是否卡滞
5. 核对温度传感器读数与实际温度是否一致

## 四、维修处理
1. 吹扫散热翅片、拆洗水冷冷却器，修复冷却风扇
2. 补充或整体更换变质润滑油，更换堵塞的油过滤器
3. 清理温控阀阀芯，卡滞严重时直接更换
4. 更换误报的温度传感器，改善机房通风

## 五、预防措施
定期更换"三滤一油"（空气滤芯、油气分离器、油过滤器、润滑油），保持散热系统清洁和机房通风，监测油温变化。
