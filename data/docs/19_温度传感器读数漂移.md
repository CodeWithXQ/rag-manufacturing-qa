# 温度传感器读数漂移故障

## 一、故障现象
温度传感器（热电偶/热电阻）显示温度与实际温度偏差越来越大，读数缓慢漂移或跳变，导致温控失准。

## 二、常见原因
1. 热电偶冷端补偿失效或补偿导线接错
2. 热电阻引线老化、接线端子氧化导致附加电阻
3. 传感器元件老化或漂移
4. 测量回路受强电干扰

## 三、排查步骤
1. 用标准温度计/标准源对比，确认偏差方向与大小
2. 检查补偿导线型号与极性是否接对
3. 测量热电阻引线电阻与接线端子接触电阻
4. 检查信号线屏蔽与接地情况

## 四、维修处理
1. 重新做冷端补偿或更换补偿导线
2. 清洁或更换氧化接线端子，重做接线
3. 更换老化漂移的传感器元件
4. 信号线改用屏蔽线并正确接地

## 五、预防措施
定期用标准源校验温度传感器，检查补偿导线与接线，做好信号屏蔽。
