# 冲压机滑块行程不稳故障

## 一、故障现象
冲压机滑块行程位置不稳定、定位不准，上下死点位置漂移，冲压深度不一致，制品尺寸波动大。

## 二、常见原因
1. 滑块导轨磨损、间隙过大
2. 曲轴连杆机构磨损、间隙变大
3. 制动器、离合器动作不良
4. 行程开关、编码器位置信号异常
5. 机身基础松动、平衡缸压力不稳

## 三、排查步骤
1. 测量滑块行程位置，统计偏差范围
2. 检查滑块导轨磨损与间隙
3. 检查曲轴连杆机构间隙
4. 检查制动器、离合器动作
5. 检查行程开关、编码器信号

## 四、维修处理
1. 调整或更换磨损的滑块导轨
2. 修复曲轴连杆机构，消除间隙
3. 检修制动器、离合器
4. 调整行程开关、更换编码器
5. 紧固机身，稳定平衡缸压力

## 五、预防措施
定期检查滑块导轨与传动机构间隙，保持制动器离合器良好，监测行程位置精度。
