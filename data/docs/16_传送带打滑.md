# 传送带打滑故障

## 一、故障现象
输送带在驱动滚筒上打滑，带速明显低于滚筒表面速度，物料输送停滞，驱动滚筒与带之间发热、冒烟。

## 二、常见原因
1. 张紧力不足，输送带松弛
2. 驱动滚筒表面包胶磨损或沾油打滑
3. 负载过重或带被卡住
4. 环境潮湿、雨天带面摩擦系数下降

## 三、排查步骤
1. 检查张紧装置行程与张紧力是否足够
2. 检查驱动滚筒表面包胶磨损情况与是否沾油
3. 确认是否超载、有无物料卡住带
4. 观察打滑是否与天气、湿度相关

## 四、维修处理
1. 调整张紧装置，增大张紧力
2. 重新包胶或清洗滚筒表面油污
3. 降低负载或排除卡阻
4. 潮湿环境加装防滑措施或烘干装置

## 五、预防措施
定期检查张紧力与滚筒包胶，控制输送量，保持滚筒面清洁干燥。
