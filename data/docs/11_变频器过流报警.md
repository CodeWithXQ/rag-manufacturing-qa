# 变频器过流报警故障

## 一、故障现象
变频器运行中报过流故障（OC），跳闸停机，重启后可能再次报警，影响电机调速运行。

## 二、常见原因
1. 负载突变或机械卡死，电机堵转
2. 加速/减速时间设置过短
3. 变频器输出侧短路或电机绕组绝缘损坏
4. 变频器容量偏小，不匹配负载

## 三、排查步骤
1. 查看报警时的频率与电流值，判断是启动加速还是运行中过流
2. 检查负载是否卡死、堵转
3. 测量电机绕组绝缘与相间电阻
4. 核对变频器额定电流与电机额定电流匹配关系

## 四、维修处理
1. 排除机械卡阻，检查传动部件
2. 适当延长加减速时间
3. 修复电机短路/绝缘问题或更换电机
4. 更换更大容量变频器

## 五、预防措施
合理设置加减速时间与转矩提升参数，定期检测电机绝缘，避免带载启动冲击。
