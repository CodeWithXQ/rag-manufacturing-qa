# 注塑机不注射或注射速度慢故障

## 一、故障现象
合模后注射动作无法进行，或注射速度明显偏慢、注射时间延长，制品充不满、缺料，射胶压力表读数偏低或无压力。

## 二、常见原因
1. 注射压力设定过低、注射速度设定过慢
2. 料筒加热温度偏低，塑料熔融不充分、流动性差
3. 喷嘴堵塞，熔体通道受阻
4. 注射电磁阀卡死或不得电
5. 注射时间设定太短
6. 射胶阀阀芯卡住、液压油不足或污染、射胶油缸泄漏

## 三、排查步骤
1. 检查注射压力、速度、时间等工艺参数设定是否正确
2. 观察料筒各区温度显示，核对是否达到原料工艺温度
3. 检查注射电磁阀线圈是否得电，用手动推动阀芯判断是否卡滞
4. 检查液压油箱油位是否正常，油液是否乳化、污染
5. 拆检喷嘴，确认是否被焦料堵塞

## 四、维修处理
1. 调高注射压力、调快注射速度，适当延长注射时间
2. 升高料筒温度至原料工艺要求
3. 拆下喷嘴加热清洗，清除堵塞焦料
4. 拆卸注射电磁阀或射胶阀，清洗阀芯及阀体
5. 补充或更换液压油，更换射胶油缸老化的密封件

## 五、预防措施
严格执行原料烘干与工艺温度制度，定期清洗喷嘴和射胶阀，保持液压油清洁，避免长期低温、低速注射。
