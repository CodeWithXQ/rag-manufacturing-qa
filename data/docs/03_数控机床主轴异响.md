# 数控机床主轴异响故障

## 一、故障现象
主轴运转时发出周期性或连续的异响（咯噔、啸叫、摩擦声），异响随转速升高而加剧，加工表面出现振纹。

## 二、常见原因
1. 主轴轴承磨损、保持架损坏或润滑不良
2. 主轴动平衡破坏（刀具、卡盘安装偏心）
3. 传动皮带松弛或张紧轮轴承损坏
4. 主轴内孔与刀具锥柄配合不良（拉刀力不足）

## 三、排查步骤
1. 空载低速运转，判断异响来自主轴本体还是传动部件
2. 用振动仪检测主轴前后轴承部位振动值
3. 检查轴承润滑油脂是否变质、缺失
4. 拆下刀具，检查锥柄配合面有无拉毛、压痕

## 四、维修处理
1. 更换磨损的主轴轴承，按规范加注润滑脂
2. 重新做刀具与主轴的动平衡
3. 张紧或更换传动皮带、张紧轮
4. 修整锥柄配合面或调整拉刀机构拉力

## 五、预防措施
建立主轴定期润滑与振动监测制度，刀具安装前清洁锥柄，避免超速超载切削。
