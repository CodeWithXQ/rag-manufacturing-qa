# 注塑机螺杆转速不稳故障

## 一、故障现象
塑化过程中螺杆转速忽快忽慢，熔体温度波动，制品出现色差、密度不均，甚至塑化计量不准确。

## 二、常见原因
1. 液压马达内部泄漏，输出扭矩波动
2. 比例流量阀（比例阀）阀芯卡滞或信号漂移
3. 转速传感器损坏或信号受干扰
4. 背压设定不当，导致负载周期性变化

## 三、排查步骤
1. 观察压力表与转速表是否同步波动，判断是液压侧还是电控侧问题
2. 检查比例阀输入信号是否稳定，用万用表测量给定电压
3. 检查转速传感器间隙与固定是否松动
4. 分段排查液压马达内泄（测量空载与负载转速差）

## 四、维修处理
1. 清洗或更换比例阀阀芯，重新标定零位与增益
2. 更换损坏的转速传感器，做好信号线屏蔽接地
3. 修复液压马达内泄（更换配油盘或柱塞）
4. 调整背压与螺杆转速匹配关系

## 五、预防措施
定期清洗液压油过滤网，检查比例阀与传感器接线，保持油液清洁度达标。
