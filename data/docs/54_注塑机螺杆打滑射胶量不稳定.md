# 注塑机螺杆打滑射胶量不稳定故障

## 一、故障现象
注射时螺杆在料筒内打滑，射胶量忽多忽少、制品重量波动大，料筒前端温度异常，预塑时螺杆空转不进料。

## 二、常见原因
1. 螺杆与料筒磨损，螺棱与内壁间隙增大，熔体沿间隙回流
2. 背压设置不合理，过高导致回料、过低导致熔体不均匀
3. 料筒各区温度不均匀，局部过热或过冷
4. 加热圈损坏，导致局部温度异常
5. 原料未充分烘干，含水分引起熔体滑移

## 三、排查步骤
1. 连续称量多个制品的重量，统计射胶量波动范围
2. 测量螺杆螺棱与料筒内壁的间隙，判断磨损程度
3. 核对背压设定值与原料工艺卡的匹配情况
4. 用测温仪逐区核对料筒实际温度与设定值
5. 检查各加热圈工作状态，确认有无损坏

## 四、维修处理
1. 螺杆磨损间隙超过 0.2mm 时更换螺杆或料筒
2. 将背压调整至 3~10MPa 的合理范围（依材料特性）
3. 检查并更换损坏的加热圈，恢复料筒温度均匀
4. 按工艺要求烘干原料

## 五、预防措施
定期测量螺杆间隙并建立磨损台账，严格控制背压与温度参数，原料使用前充分烘干，避免杂质磨损螺杆。
