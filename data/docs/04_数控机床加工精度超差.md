# 数控机床加工精度超差故障

## 一、故障现象
加工零件尺寸超差、圆度/圆柱度不合格，重复定位精度下降，同一程序加工出的零件尺寸漂移。

## 二、常见原因
1. 滚珠丝杠反向间隙过大或丝杠螺母磨损
2. 导轨（线轨/硬轨）磨损、预紧力变化
3. 机床热变形（主轴温升导致立柱/床身变形）
4. 伺服参数（位置环增益、反向间隙补偿）设置不当

## 三、排查步骤
1. 用激光干涉仪检测各轴定位精度与反向间隙
2. 检查丝杠螺母预紧是否松动，测量反向间隙
3. 检测主轴长时间运转后的温升，评估热变形
4. 核对系统反向间隙补偿值与螺距误差补偿值

## 四、维修处理
1. 重新调整丝杠螺母预紧或更换磨损丝杠
2. 调整导轨预紧力，修复磨损导轨面
3. 增加主轴冷却，做热补偿标定
4. 重新进行反向间隙与螺距误差补偿

## 五、预防措施
定期做精度检测与补偿，控制车间温度，避免长期连续超负荷切削。
