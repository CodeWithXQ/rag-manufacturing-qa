# 注塑机调模困难故障

## 一、故障现象
更换模具后调整模板间距时，调模动作缓慢、卡滞或完全无法进行，模板移动阻力大，调模电机/液压马达过载。

## 二、常见原因
1. 系统调模压力调节过低
2. 后模板拉杆螺母因杂质或缺少润滑油脂而卡死
3. 调模电磁阀卡死或插座松动
4. 调模液压马达损坏
5. 四根拉杆螺母轴向间隙不一致，导致受力不均卡滞

## 三、排查步骤
1. 检查调模压力设定值是否偏低
2. 检查拉杆螺母表面有无杂质、锈蚀，润滑是否充足
3. 检查调模电磁阀线圈是否得电、阀芯是否卡滞
4. 检查调模液压马达运转情况
5. 测量四根拉杆螺母的轴向间隙是否一致

## 四、维修处理
1. 调高系统调模压力至正常范围
2. 清洗拉杆螺母，修复螺纹，加注润滑油脂
3. 拆卸清洗或更换调模电磁阀，重新插紧插座
4. 修理或更换调模液压马达
5. 调整四根拉杆螺母的轴向间隙，使其保持一致

## 五、预防措施
保持拉杆螺母清洁并定期润滑，调整时保证四根拉杆间隙一致，定期检查调模电磁阀与液压马达。
