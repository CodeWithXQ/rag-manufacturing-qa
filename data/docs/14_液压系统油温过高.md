# 液压系统油温过高故障

## 一、故障现象
液压油箱油温持续升高（超过 55-60℃），油液粘度下降、泄漏增大，密封件老化加速，系统效率降低。

## 二、常见原因
1. 冷却器堵塞或冷却水流量不足
2. 溢流阀长时间高压溢流，能量转化为热量
3. 油位过低或油液污染，散热不良
4. 系统设计不合理，油箱容量偏小

## 三、排查步骤
1. 测量进出冷却器的油温与水温差，判断冷却效果
2. 观察溢流阀是否长时间处于溢流状态
3. 检查油位、油液颜色与污染程度
4. 检查冷却水管路是否堵塞、阀门是否全开

## 四、维修处理
1. 清洗冷却器，保证冷却水流量
2. 优化系统，避免长时间高压溢流
3. 补足油液、更换污染变质的液压油
4. 必要时加大油箱或增加强制散热装置

## 五、预防措施
监控油温，定期清洗冷却器与更换液压油，合理匹配系统压力与流量。
