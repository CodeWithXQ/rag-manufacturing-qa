# 空压机主机异响故障

## 一、故障现象
空压机主机（螺杆机头）运转时发出金属撞击或摩擦异响，异响随负载变化，机组振动加剧。

## 二、常见原因
1. 螺杆转子轴承磨损
2. 阴阳转子间隙失调或碰擦
3. 进气阀异物进入机头
4. 联轴器弹性体磨损

## 三、排查步骤
1. 停机盘车听转子有无周期性卡滞
2. 用听棒定位异响来自轴承侧还是转子侧
3. 检查进气滤芯是否破损漏入异物
4. 检查联轴器弹性体磨损情况

## 四、维修处理
1. 更换磨损的转子轴承
2. 重新调整转子间隙或返厂大修
3. 清除机头异物、更换进气滤芯
4. 更换联轴器弹性体

## 五、预防措施
定期更换进气滤芯，监控机组振动值，发现异响及时停机检查。
