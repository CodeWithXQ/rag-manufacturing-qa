# 液压系统噪音振动故障

## 一、故障现象
液压系统运行时发出异常噪音和振动，泵站嗡嗡声、啸叫声明显，管路抖动，噪音随压力升高而加剧。

## 二、常见原因
1. 油箱油位过低、吸油管漏气或过滤器堵塞，导致油泵吸空混入空气
2. 油泵叶片、齿轮磨损，产生机械噪音
3. 管路共振或管路固定不良，与其它部件碰撞
4. 油液含气泡，油箱密封不良
5. 油液粘度过高或油温过低

## 三、排查步骤
1. 检查油箱油位是否过低，吸油管是否漏气
2. 检查过滤器是否堵塞
3. 观察噪音来源，判断是油泵、阀件还是管路共振
4. 检查管路固定情况，有无松动碰撞
5. 检查油液是否含气泡、粘度是否合适

## 四、维修处理
1. 补充油液，密封吸油管接头，清洗过滤器
2. 更换油泵磨损部件
3. 加固管路，调整管夹位置，消除共振
4. 更换含气泡的油液，密封油箱
5. 更换合适粘度的液压油，改善油温

## 五、预防措施
保持油位正常、油液清洁，定期检查管路固定与密封，避免油泵吸空，选用合适粘度的液压油。
