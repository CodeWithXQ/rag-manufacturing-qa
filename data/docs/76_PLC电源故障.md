# PLC 电源故障

## 一、故障现象
PLC 上电后 POWER 电源指示灯不亮或闪烁，CPU 无法启动，输入输出模块无供电，整机无反应。

## 二、常见原因
1. 外部供电电源缺失、电压过低或波动过大
2. 电源保险丝熔断
3. 开关电源或电源模块损坏
4. 电源接线松动、端子接触不良
5. 电源模块输出短路（负载侧短路）

## 三、排查步骤
1. 用万用表测量外部供电电压是否正常
2. 检查电源保险丝是否熔断
3. 观察电源模块指示灯状态，判断电源模块是否工作
4. 检查电源接线端子是否紧固
5. 断开负载，判断是否负载短路导致电源保护

## 四、维修处理
1. 恢复外部供电，排除电压波动
2. 更换熔断的保险丝
3. 更换损坏的开关电源或电源模块
4. 紧固电源接线端子
5. 排除负载侧短路，恢复供电

## 五、预防措施
PLC 供电建议加装稳压电源或 UPS，定期检查电源端子紧固与保险丝状态，避免与动力设备共用一路电源。
