# 空压机排气温度过高故障

## 一、故障现象
空压机运行中排气温度持续升高并触发高温报警停机，油气分离器温度异常，机组效率下降。

## 二、常见原因
1. 冷却器（风冷散热片/水冷管程）堵塞或结垢
2. 润滑油量不足或油品变质，冷却润滑不良
3. 环境温度过高、通风不畅
4. 温控阀故障，润滑油不经过冷却器直接回机头

## 三、排查步骤
1. 检查冷却器散热片是否积灰堵塞，水冷则检查进出水温差
2. 检查油位是否正常，取样观察油品颜色与粘度
3. 测量机房环境温度与通风情况
4. 检查温控阀芯是否卡死在旁通位置

## 四、维修处理
1. 清洗冷却器（风冷用高压气吹扫，水冷做化学除垢）
2. 补足或更换润滑油，检查油滤
3. 改善机房通风，降低环境温度
4. 更换或维修温控阀

## 五、预防措施
按周期清洗冷却器与更换油滤，监控排气温度趋势，保证机房通风散热。
