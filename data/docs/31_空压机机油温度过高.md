# 空压机机油温度过高故障

## 一、故障现象
空压机运行中机油温度持续升高，油品加速老化变黑，机组过热报警停机。

## 二、常见原因
1. 机油冷却器堵塞或水垢结垢
2. 机油油位过低或油品粘度过高
3. 机头磨损导致摩擦生热加剧
4. 温控阀卡滞，机油不经过冷却器

## 三、排查步骤
1. 测量机油冷却器进出油温与水温差
2. 检查机油油位与油品粘度、颜色
3. 检测机头排气侧温度与异响
4. 检查温控阀是否卡死在旁通位

## 四、维修处理
1. 清洗机油冷却器，化学除垢
2. 补足或更换合适粘度的机油
3. 检修机头轴承与转子间隙
4. 更换或维修温控阀

## 五、预防措施
按周期更换机油与清洗冷却器，监控油温趋势，保持油位正常。
