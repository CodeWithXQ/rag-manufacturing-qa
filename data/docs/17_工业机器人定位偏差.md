# 工业机器人定位偏差故障

## 一、故障现象
机器人末端执行器实际到达位置与示教位置偏差增大，重复定位精度下降，作业质量（焊接/装配/搬运）不合格。

## 二、常见原因
1. 减速机（RV/谐波）磨损，反向间隙增大
2. 编码器零位漂移或丢失
3. 机械臂结构件松动或变形
4. 工具坐标系（TCP）未标定或标定失效

## 三、排查步骤
1. 用激光跟踪仪或百分表检测各轴重复定位精度
2. 检查减速机反向间隙与异响
3. 核对各轴编码器零位与电池电量
4. 重新做 TCP 标定，检查工具是否松动

## 四、维修处理
1. 更换磨损的减速机或调整其预紧
2. 重新设置编码器零位、更换电池
3. 紧固松动的结构件，校正变形
4. 重新标定 TCP 与工具坐标

## 五、预防措施
定期做精度检测与 TCP 标定，及时更换编码器电池，避免超载与碰撞。
