# 润滑系统油压报警故障

## 一、故障现象
润滑系统油压低于设定值触发报警，各润滑点供油不足，运动部件磨损加剧甚至抱死。

## 二、常见原因
1. 润滑油泵磨损或电机故障
2. 油滤芯堵塞，油路阻力增大
3. 管路泄漏或分油器堵塞
4. 润滑油液位过低或油品粘度过高

## 三、排查步骤
1. 检查油泵运行状态与出口压力
2. 检查油滤芯是否堵塞、压差是否过大
3. 检查管路有无泄漏、分油器是否堵塞
4. 检查油箱液位与油品粘度

## 四、维修处理
1. 检修或更换润滑油泵
2. 更换堵塞的油滤芯
3. 修复泄漏点、疏通或更换分油器
4. 补足润滑油、更换合适粘度油品

## 五、预防措施
定期更换油滤芯与润滑油，检查油泵压力，监测油压趋势，做好润滑点检。
