# 注塑机合模不到位故障

## 一、故障现象
按下合模按钮后，动模板无法闭合到位或中途停止，锁模指示灯不亮，无法进行后续注射动作，或合模速度明显变慢。

## 二、常见原因
1. 安全门行程开关（SQ1、SQ2、SQ3）接线松动、损坏，或安全门未压到位
2. 安全门联锁行程开关 SQ4 已闭合（本应断开）
3. 锁模电磁阀阀芯卡死，或电磁阀插座松动不得电
4. 顶针后退行程开关未闭合
5. 系统无压力，锁模液压回路供油不足

## 三、排查步骤
1. 检查安全门是否关严，行程开关 SQ1、SQ2、SQ3 是否被可靠压下
2. 检查 SQ4 行程开关状态是否正常
3. 检查锁模电磁阀线圈是否得电，手动推动阀芯判断是否卡滞
4. 检查顶针后退行程开关是否闭合
5. 观察系统压力表，确认液压系统压力是否建立

## 四、维修处理
1. 调整或更换松动的安全门行程开关，确保门关闭到位
2. 修复 SQ4 行程开关，恢复正确联锁状态
3. 拆卸清洗锁模电磁阀，重新插紧或更换电磁阀插座
4. 调整顶针后退行程开关位置
5. 按起压问题排查流程修复系统压力

## 五、预防措施
定期检查安全门联锁开关与行程开关的紧固和磨损情况，保持锁模电磁阀清洁，确保液压系统压力稳定。
