# 数控机床进给轴无动作故障

## 一、故障现象
执行进给指令后某坐标轴不动或移动异常，系统报伺服相关报警或位置偏差过大，轴无法定位。

## 二、常见原因
1. 伺服驱动器报警或未使能
2. 进给轴电机故障（编码器、绕组、抱闸）
3. 机械传动卡滞，丝杠、导轨润滑不良或损坏
4. 进给轴行程开关、限位开关信号异常
5. CNC 位置控制参数或软限位设置错误

## 三、排查步骤
1. 观察伺服驱动器报警代码，判断故障类型
2. 检查进给轴使能信号与电机抱闸状态
3. 手动盘动丝杠，判断机械部分是否卡滞
4. 检查导轨、丝杠润滑情况
5. 核对行程开关与软限位参数设置

## 四、维修处理
1. 按伺服驱动器报警代码排查，复位或更换驱动模块
2. 更换故障电机或编码器，恢复抱闸
3. 疏通润滑，检修卡滞的丝杠、导轨
4. 调整或更换行程开关、限位开关
5. 修正位置控制参数与软限位设置

## 五、预防措施
定期检查伺服系统与机械传动，保持导轨丝杠润滑，监测行程开关状态，避免碰撞冲击导致机械损坏。
