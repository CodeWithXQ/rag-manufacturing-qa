# 数控机床主轴无法旋转故障

## 一、故障现象
执行主轴旋转指令后主轴不转或转速异常，系统可能无报警或报主轴相关报警，加工无法进行。

## 二、常见原因
1. 主轴驱动系统故障（直流或交流主轴驱动器、FANUC 模拟/串行主轴）
2. CNC 与 PMC 控制信号异常，主轴使能信号未发出
3. 电气部分故障，如接触器、继电器、保险损坏
4. 机械传动部分故障，如主轴箱内齿轮、皮带打滑断裂
5. 主轴组件本身故障，轴承卡死

## 三、排查步骤
1. 观察系统有无主轴相关报警，读取诊断号判断故障部位
2. 检查主轴使能、正反转信号是否正常发出
3. 检查主轴驱动器有无故障代码显示
4. 检查主轴电机供电、接触器、保险丝
5. 检查机械传动皮带、齿轮是否打滑断裂，手动盘动主轴判断是否卡死

## 四、维修处理
1. 按主轴驱动器报警代码更换或维修驱动模块
2. 排查 CNC/PMC 信号链，恢复主轴使能信号
3. 更换损坏的接触器、继电器、保险丝
4. 更换断裂皮带、修复齿轮传动
5. 检修主轴轴承与组件，解除卡滞

## 五、预防措施
定期点检主轴驱动系统与电气元件，监测主轴运行状态，避免机械过载冲击，建立主轴报警历史记录。
