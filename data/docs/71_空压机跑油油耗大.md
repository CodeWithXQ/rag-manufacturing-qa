# 空压机跑油油耗大故障

## 一、故障现象
空压机润滑油消耗过快，需频繁补油，排气含油量大、出气口跑油，机身或管路渗油，压缩空气质量下降。

## 二、常见原因
1. 油气分离器滤芯堵塞、失效或破裂，油气分离不彻底
2. 回油单向阀、回油滤网堵塞，分离后的润滑油无法回流而积油外泄
3. 润滑油添加过量，油位过高
4. 主机轴封、油封老化破损，机身渗油漏油
5. 机组长期低压空载运行，油气分离效率下降

## 三、排查步骤
1. 检查排气含油情况，观察油气分离器前后压差
2. 检查回油管路与单向阀、滤网是否堵塞
3. 核对润滑油油位是否过高（加载时油位应不高于一半）
4. 检查主机轴封、油封有无渗漏
5. 了解机组运行工况，是否长期低压空载

## 四、维修处理
1. 更换失效、堵塞或破裂的油气分离器滤芯
2. 拆解疏通回油管路与单向阀，清理滤网
3. 调整润滑油油位至标准范围
4. 更换老化破损的轴封、油封
5. 避免长期低压空载运行，使用正确规格润滑油

## 五、预防措施
定期更换油气分离器滤芯，保持回油管路畅通，严格控制油位，使用专用润滑油并避免长期低压运行。
