# 伺服电机编码器报警故障

## 一、故障现象
伺服驱动器报编码器相关故障（如编码器断线、计数错误、绝对值位置丢失），电机无法正常定位或停机。

## 二、常见原因
1. 编码器信号线断线、接触不良
2. 编码器电缆屏蔽不良受干扰
3. 编码器供电电压异常
4. 编码器本身损坏或绝对位置电池掉电

## 三、排查步骤
1. 读取驱动器报警代码，确定故障类型
2. 检查编码器电缆插头与接线端子
3. 测量编码器供电电压（通常 5V）
4. 检查绝对编码器电池电压是否过低

## 四、维修处理
1. 重新接好或更换编码器信号线
2. 加强电缆屏蔽、正确接地
3. 修复编码器供电
4. 更换编码器或更换绝对位置电池并重新回零

## 五、预防措施
定期检查编码器电缆与电池，避免拖链内线缆过度弯折，做好屏蔽接地。
