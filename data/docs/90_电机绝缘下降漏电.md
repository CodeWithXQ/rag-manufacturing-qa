# 电机绝缘下降漏电故障

## 一、故障现象
电机绝缘电阻明显下降，外壳带电或漏电保护跳闸，绕组对地短路，电机运行中报漏电故障或烧保险。

## 二、常见原因
1. 电机受潮，绕组绝缘吸湿
2. 绕组绝缘老化、过热损伤
3. 绕组端部积尘、油污导致爬电
4. 机械损伤、异物划伤绕组绝缘
5. 长期过载运行导致绝缘热老化

## 三、排查步骤
1. 用兆欧表测量绕组对地绝缘电阻（正常应大于 0.5MΩ）
2. 检查电机是否受潮，接线盒有无进水
3. 观察绕组端部有无积尘、油污
4. 检查绕组有无机械损伤、绝缘破损
5. 了解电机运行工况，判断是否长期过载

## 四、维修处理
1. 受潮电机做干燥处理，恢复绝缘
2. 更换绝缘老化的绕组或重新浸漆
3. 清理绕组端部积尘、油污
4. 修复绝缘破损部位
5. 排除过载原因，避免绝缘继续热老化

## 五、预防措施
保持电机干燥清洁，避免受潮进水，定期测量绝缘电阻，防止长期过载运行导致绝缘加速老化。
