# 车床主轴振动故障

## 一、故障现象
车削加工时主轴产生明显振动，工件表面出现振纹，加工精度下降，伴随周期性噪声。

## 二、常见原因
1. 主轴轴承磨损、间隙过大
2. 卡盘或工件装夹不平衡
3. 主轴箱传动齿轮磨损或啮合不良
4. 地脚螺栓松动或床身刚度不足

## 三、排查步骤
1. 空载运转判断振动是来自主轴还是传动系统
2. 检查主轴轴承间隙与温升
3. 重新装夹工件，做动平衡检查
4. 检查地脚螺栓与床身水平

## 四、维修处理
1. 调整或更换主轴轴承
2. 重新平衡卡盘与工件
3. 更换磨损齿轮、调整啮合间隙
4. 紧固地脚螺栓、调整床身水平

## 五、预防措施
定期检查主轴轴承间隙，装夹前做平衡，保持床身水平，避免超载切削。
