# 数控机床主轴振动故障

## 一、故障现象
数控机床主轴高速运转时振动明显，加工表面出现振纹，刀具磨损加快，振动随转速升高加剧。

## 二、常见原因
1. 主轴轴承预紧力不足或磨损
2. 刀具系统动平衡不良
3. 主轴与电机联轴器不对中
4. 切削参数不当引起颤振

## 三、排查步骤
1. 空载测主轴不同转速下的振动值
2. 检查刀具与刀柄的动平衡
3. 检查主轴与电机联轴器对中
4. 复核切削参数是否引起颤振

## 四、维修处理
1. 调整轴承预紧或更换轴承
2. 重新做刀具系统动平衡
3. 校正联轴器同轴度
4. 调整切削参数避开颤振区

## 五、预防措施
定期监测主轴振动，刀具安装前做平衡，合理选择切削参数。
