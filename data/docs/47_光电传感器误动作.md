# 光电传感器误动作故障

## 一、故障现象
光电传感器在无物体遮挡时误输出信号，或检测不到物体，导致计数错误、定位偏差。

## 二、常见原因
1. 传感器镜头脏污或被遮挡
2. 环境光干扰（强光、反光）
3. 检测距离或灵敏度设置不当
4. 传感器与反射板/被测物对中不良

## 三、排查步骤
1. 清洁传感器镜头与反射板
2. 检查环境光干扰源
3. 调整检测距离与灵敏度
4. 检查传感器对中情况

## 四、维修处理
1. 清洁镜头、消除遮挡
2. 加装遮光罩或调整安装角度
3. 重新设定检测距离与灵敏度
4. 重新对中传感器与反射板

## 五、预防措施
定期清洁传感器镜头，避免强光直射，合理设置检测参数。
