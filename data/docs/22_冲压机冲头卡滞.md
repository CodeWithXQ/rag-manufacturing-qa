# 冲压机冲头卡滞故障

## 一、故障现象
冲压机滑块（冲头）上下运动不顺畅，出现卡滞、爬行或无法回程，伴随异常摩擦声。

## 二、常见原因
1. 导柱/导套润滑不良或磨损拉伤
2. 滑块导轨间隙过小或调整不当
3. 模具导向部件损坏或对中不良
4. 平衡缸压力不足

## 三、排查步骤
1. 检查导柱、导套润滑情况，观察有无拉伤痕
2. 测量滑块导轨间隙是否过小
3. 检查模具导向与对中情况
4. 检查平衡缸压力是否正常

## 四、维修处理
1. 恢复润滑、修磨或更换拉伤的导柱导套
2. 重新调整导轨间隙
3. 修复模具导向、重新对中
4. 调整平衡缸压力至规定值

## 五、预防措施
严格执行润滑制度，定期检查导轨间隙与模具导向，避免超载冲压。
