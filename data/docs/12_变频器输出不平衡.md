# 变频器输出不平衡故障

## 一、故障现象
变频器三相输出电压/电流不平衡，电机运行振动增大、温升不均，有时伴随异常噪声。

## 二、常见原因
1. 变频器功率模块（IGBT）某一相损坏
2. 驱动电路故障导致某相未正常导通
3. 电机绕组三相不平衡或某相接地
4. 输出电缆某相接触不良

## 三、排查步骤
1. 用钳形表分别测量变频器输出三相电流并比较
2. 断电后拆开输出线，测量电机三相绕组电阻
3. 用万用表二极管档检查 IGBT 模块
4. 检查输出接线端子是否松动、氧化

## 四、维修处理
1. 更换损坏的 IGBT 功率模块
2. 检修驱动电路或更换驱动板
3. 修复电机绕组不平衡或更换电机
4. 紧固输出端子，更换受损电缆

## 五、预防措施
定期检查输出接线与电机绝缘，避免频繁启停冲击，做好散热防止功率模块过热。
