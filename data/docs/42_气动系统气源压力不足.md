# 气动系统气源压力不足故障

## 一、故障现象
气源压力低于设定值，气动执行元件动作无力，多个气缸同时动作时压力明显下降。

## 二、常见原因
1. 空压机供气量不足或压力设定低
2. 管路泄漏
3. 过滤器、减压阀堵塞
4. 储气罐容量不足

## 三、排查步骤
1. 检查空压机出口压力与运行状态
2. 用检漏剂检查管路接头泄漏
3. 检查过滤器、减压阀是否堵塞
4. 评估储气罐容量与用气量

## 四、维修处理
1. 提高空压机压力设定或检修空压机
2. 封堵泄漏点
3. 清洗或更换过滤器、减压阀
4. 增大储气罐容量

## 五、预防措施
定期检漏与维护气源三联件，合理匹配空压机与储气罐容量。
