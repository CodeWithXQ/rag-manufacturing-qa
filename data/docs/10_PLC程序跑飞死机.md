# PLC 程序跑飞死机故障

## 一、故障现象
PLC 运行中突然停止扫描、输出保持或全无，程序不按逻辑执行，指示灯异常，设备失控或急停。

## 二、常见原因
1. 强电磁干扰导致 CPU 程序跑飞
2. 程序存在死循环、指针越界等逻辑缺陷
3. 电源波动导致 CPU 复位
4. 看门狗（WDT）超时未被喂狗

## 三、排查步骤
1. 观察 CPU 指示灯（RUN/ERROR），读取故障代码
2. 检查是否有大功率变频器、接触器等强干扰源
3. 复核程序逻辑，重点查循环与指针/间接寻址
4. 检查 PLC 供电电源是否稳定（有无瞬时跌落）

## 四、维修处理
1. 增强接地与屏蔽，加装隔离变压器或电源滤波器
2. 修正程序死循环、越界等逻辑缺陷
3. 加装 UPS 或稳压电源保证供电稳定
4. 合理设置看门狗并保证主循环及时喂狗

## 五、预防措施
程序编写遵循规范，PLC 与动力线分开走线，接地良好，供电加滤波稳压。
