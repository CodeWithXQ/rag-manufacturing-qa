# 注塑机锁模时异常声响故障

## 一、故障现象
合模或锁模过程中，锁模机构发出异常撞击声、吱嘎声或金属摩擦声，声音随锁模动作周期性出现，严重时伴随模板抖动。

## 二、常见原因
1. 锁模机构（曲肘、连杆、销轴）润滑不足，干摩擦产生异响
2. 连接件松动，如模板螺丝、连杆接头、拉杆螺母松动
3. 模板平行度偏差，四根拉杆受力不均，局部应力集中
4. 曲肘销轴与铜套磨损，配合间隙过大

## 三、排查步骤
1. 在锁模过程中用听诊器或金属棒贴近曲肘、拉杆部位，定位异响来源
2. 检查各润滑点是否缺油，观察曲肘部位有无干磨痕迹
3. 用扳手逐个检查模板螺丝、连杆接头、拉杆螺母的紧固情况
4. 用百分表测量动、定模板平行度，判断是否超差

## 四、维修处理
1. 定期加注锂基润滑脂，确保曲肘、销轴润滑充分
2. 紧固所有松动的连接件
3. 检测模板平行度，偏差超过 0.05mm 时调整拉杆预紧力或修复模板
4. 更换磨损的曲肘销轴与铜套

## 五、预防措施
建立锁模机构定期润滑制度，定期检测模板平行度与拉杆受力，紧固连接件，及时更换磨损的销轴铜套。
