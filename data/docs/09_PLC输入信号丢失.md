# PLC 输入信号丢失故障

## 一、故障现象
PLC 控制系统中，某个或某些输入点信号时有时无或完全丢失，导致程序无法采集到现场开关/传感器状态，设备误动作或停机。

## 二、常见原因
1. 输入端子接线松动、氧化或断路
2. 现场传感器损坏或供电异常
3. 输入模块光电隔离器件损坏
4. 强电干扰导致信号抖动或被屏蔽

## 三、排查步骤
1. 观察 PLC 输入点指示灯，判断是现场信号问题还是模块问题
2. 用万用表在输入端子上测量信号电压
3. 检查现场传感器供电与输出是否正常
4. 检查输入公共端（COM）接线是否可靠接地

## 四、维修处理
1. 紧固或重做松动的输入端子接线
2. 更换损坏的传感器或修复其供电
3. 更换损坏的输入模块
4. 信号线采用屏蔽线并单独走线，远离动力线

## 五、预防措施
定期紧固接线端子，输入信号线屏蔽接地，规范走线，避免与强电共管。
