# 空压机频繁启停故障

## 一、故障现象
空压机在短时间内反复加载/卸载或启停，压力波动大，电机频繁启动冲击电网，机组寿命缩短。

## 二、常见原因
1. 供气管路存在泄漏，压力下降过快触发加载
2. 压力开关（压力传感器）死区设置过小或漂移
3. 用气量波动大，储气罐容量不足
4. 卸载阀/进气阀动作失灵

## 三、排查步骤
1. 停机后关闭储气罐出口阀，观察压力是否快速下降以判断泄漏
2. 检查压力开关的设定值与回差（上下限）
3. 统计用气高峰与低谷，评估储气罐是否偏小
4. 检查进气阀是否卡滞、卸载时是否正常关闭

## 四、维修处理
1. 用检漏剂查找并封堵泄漏点
2. 重新设定压力开关上下限，增大回差
3. 增大储气罐容量或加装变频控制
4. 清洗或更换进气阀、卸载阀

## 五、预防措施
定期检查管路密封性，合理设置压力参数，按用气规律优化机组配置。
