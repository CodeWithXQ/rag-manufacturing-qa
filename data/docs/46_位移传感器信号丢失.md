# 位移传感器信号丢失故障

## 一、故障现象
位移传感器输出信号突然丢失或跳变为零，控制系统无法获取位置，设备停机或误动作。

## 二、常见原因
1. 传感器供电异常或断线
2. 信号线断路、短路或接触不良
3. 传感器内部元件损坏
4. 传感器与被测物间隙超差

## 三、排查步骤
1. 测量传感器供电电压
2. 检查信号线与接线端子通断
3. 检查传感器与被测物安装间隙
4. 替换法判断传感器是否损坏

## 四、维修处理
1. 恢复或修复供电
2. 修复信号线、重做接线
3. 调整安装间隙
4. 更换损坏传感器

## 五、预防措施
定期检查传感器供电与接线，保证安装间隙，避免机械碰撞。
