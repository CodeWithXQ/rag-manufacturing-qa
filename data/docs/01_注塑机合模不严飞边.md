# 注塑机合模不严导致飞边故障

## 一、故障现象
注塑成型时，制品分型面、镶件周边出现多余薄片状塑料（飞边/披锋），模具合模后仍可见明显缝隙，锁模指示灯虽亮但合模力不足。

## 二、常见原因
1. 锁模力设定偏小，小于注射压力在模腔内产生的胀模力
2. 模板平行度超差，四根拉杆受力不均
3. 模具分型面有异物、磨损或变形
4. 锁模机构（曲肘）磨损，无法达到标称锁模力

## 三、排查步骤
1. 核对锁模力设定值，与工艺卡片比对
2. 用塞尺测量合模后分型面间隙，判断是否均匀
3. 检查四根拉杆的应变，确认受力是否一致
4. 清洁分型面，检查有无异物、毛刺

## 四、维修处理
1. 提高锁模力至合理值（一般取胀模力的 1.1-1.3 倍）
2. 重新校正模板平行度，调整拉杆预紧力
3. 对分型面进行研磨修复或更换磨损镶件
4. 更换磨损的曲肘销轴与铜套

## 五、预防措施
定期检测锁模力与模板平行度，保持分型面清洁，建立模具点检台账。
