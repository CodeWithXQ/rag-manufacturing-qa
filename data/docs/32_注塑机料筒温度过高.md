# 注塑机料筒温度过高故障

## 一、故障现象
注塑机料筒加热段温度超过设定值，塑料分解产生黄斑、气泡，制品质量下降甚至碳化。

## 二、常见原因
1. 热电偶测温失准，反馈温度偏低导致持续加热
2. 加热圈继电器触点粘连
3. 冷却风机或冷却水故障
4. 料筒保温层破损

## 三、排查步骤
1. 用标准温度计比对料筒实际温度与显示值
2. 检查加热圈继电器是否粘连常通
3. 检查冷却风机运转与冷却水流量
4. 检查保温层是否破损

## 四、维修处理
1. 校准或更换失准的热电偶
2. 更换粘连的加热继电器
3. 修复冷却风机或冷却水回路
4. 修复保温层

## 五、预防措施
定期校验热电偶，点检加热继电器与冷却系统，防止料筒超温分解塑料。
