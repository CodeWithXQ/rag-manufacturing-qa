# 电机振动异响故障

## 一、故障现象
电机运行中振动过大、发出异常声响，机体抖动，地脚螺栓松动，振动随转速变化，严重时影响设备精度。

## 二、常见原因
1. 转子不平衡或转子与定子气隙不均匀
2. 轴承磨损、缺油或损坏
3. 地脚螺栓松动、基础不平
4. 联轴器不对中、同心度超差
5. 定子绕组局部短路、三相电流不平衡

## 三、排查步骤
1. 用测振仪测量电机各部位振动值，判断振源
2. 检查地脚螺栓与基础水平
3. 检查轴承润滑与磨损情况
4. 检查联轴器对中情况
5. 测量三相电流是否平衡

## 四、维修处理
1. 转子做动平衡校正，调整气隙均匀
2. 更换磨损轴承，补充润滑
3. 紧固地脚螺栓，调整基础水平
4. 重新对中联轴器
5. 修复绕组短路，排除三相不平衡

## 五、预防措施
定期检测电机振动并建立趋势记录，保持轴承润滑与联轴器对中，避免电机长期三相不平衡运行。
