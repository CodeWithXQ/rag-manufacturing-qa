# 水泵压力不足故障

## 一、故障现象
水泵出口压力达不到额定值，供水流量不足，扬程不够，末端设备水压偏低。

## 二、常见原因
1. 叶轮磨损或汽蚀
2. 泵内泄漏或密封环间隙过大
3. 电机转速不足（电压低/频率低）
4. 吸水管漏气或吸入阻力大

## 三、排查步骤
1. 测出口压力与电机转速
2. 检查叶轮磨损与密封环间隙
3. 检查吸水管密封、过滤器堵塞
4. 检查电机电压与供电

## 四、维修处理
1. 更换磨损叶轮、调整密封环间隙
2. 修复泵内泄漏
3. 修复供电保证额定转速
4. 疏通吸水管、封堵漏气

## 五、预防措施
定期检查叶轮与密封环，保证吸水管密封，监测出口压力与流量。
