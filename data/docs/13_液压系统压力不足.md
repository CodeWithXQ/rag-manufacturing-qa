# 液压系统压力不足故障

## 一、故障现象
液压系统工作压力达不到设定值，执行元件（油缸/马达）动作无力、速度慢，甚至无法带动负载。

## 二、常见原因
1. 溢流阀设定值偏低或阀芯卡滞、弹簧疲劳
2. 液压泵磨损，容积效率下降，内泄增大
3. 液压缸或换向阀内泄，压力油直接回油箱
4. 油液粘度过低或油位不足，泵吸油不畅

## 三、排查步骤
1. 观察压力表读数，调节溢流阀看压力能否上升
2. 检查油箱油位与油液粘度、是否混入空气
3. 分段封堵油路，用测压法定位内泄点
4. 检测液压泵空载与负载下的流量

## 四、维修处理
1. 重新设定或清洗、更换溢流阀
2. 更换磨损的液压泵或柱塞、配油盘
3. 更换内泄的液压缸密封件或换向阀
4. 补足油液、更换合适粘度液压油

## 五、预防措施
定期检测油液清洁度与油位，按周期更换油泵密封，保持溢流阀设定值合理。
