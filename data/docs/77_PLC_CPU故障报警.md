# PLC CPU 故障报警

## 一、故障现象
PLC 的 CPU 模块 ERR 或 ERROR 故障灯常亮或闪烁，程序停止运行，输出全部断开，无法执行控制逻辑。

## 二、常见原因
1. 用户程序错误导致 CPU 停机（如数据溢出、非法指令）
2. 存储卡或内存故障导致程序丢失
3. I/O 总线或扩展模块故障
4. CPU 内部硬件故障
5. 电池电量耗尽导致保持区数据丢失
6. 扫描周期超时（看门狗超时）

## 三、排查步骤
1. 观察故障灯状态（常亮/闪烁），结合编程软件读取诊断信息
2. 通过编程软件查看 CPU 诊断缓冲区，定位故障代码
3. 检查程序是否有数据溢出、非法访问等错误
4. 检查 I/O 扩展模块与总线连接
5. 检查电池状态与存储卡

## 四、维修处理
1. 根据诊断信息修正用户程序，重新下载
2. 更换故障存储卡或内存模块，恢复程序
3. 重新插拔或更换 I/O 扩展模块
4. 更换 CPU 模块（硬件故障时）
5. 更换电池，恢复保持区数据
6. 优化程序，缩短扫描周期

## 五、预防措施
定期备份 PLC 程序，监测电池电量并及时更换，避免程序数据溢出，保持 I/O 扩展模块连接可靠。
