# 流量传感器读数异常故障

## 一、故障现象
流量传感器显示值跳变、偏大或偏小，与实际流量不符，影响计量与控制精度。

## 二、常见原因
1. 传感器内壁结垢或杂质附着
2. 信号线受电磁干扰
3. 传感器安装位置不符合直管段要求
4. 传感器参数设置或标定错误

## 三、排查步骤
1. 与标准流量计比对读数
2. 检查传感器内壁有无结垢
3. 检查信号线屏蔽与接地
4. 核对安装直管段与参数设置

## 四、维修处理
1. 清洗传感器内壁
2. 加强信号线屏蔽、正确接地
3. 调整安装位置满足直管段要求
4. 重新标定或修正参数

## 五、预防措施
定期校验流量传感器，保持管道清洁，规范安装与走线。
