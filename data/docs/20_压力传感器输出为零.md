# 压力传感器输出为零故障

## 一、故障现象
压力传感器输出信号恒为零或接近零，上位机显示压力为零，即使系统实际有压力也无变化。

## 二、常见原因
1. 传感器供电电源缺失或电压不足
2. 信号线断路、短路或接线错误
3. 传感器内部应变片/膜片损坏
4. 变送器（放大器）故障

## 三、排查步骤
1. 用万用表测量传感器供电电压是否正常
2. 检查信号线与接线端子是否断路、短路
3. 断开负载测传感器输出（电流型测 4-20mA，电压型测电压）
4. 用标准压力源打压，观察输出是否跟随变化

## 四、维修处理
1. 恢复或修复供电电源
2. 修复信号线断路、短路，重做接线
3. 更换损坏的压力传感器
4. 更换或维修变送器

## 五、预防措施
定期检查传感器供电与接线，避免信号线与动力线混走，做好防水防潮。
