# 伺服电机抖动振荡故障

## 一、故障现象
伺服电机运行或停止时出现抖动、振荡，电机轴高频震动，定位时来回摆动无法稳定，伴有啸叫或嗡嗡声。

## 二、常见原因
1. 伺服增益参数设置过高，系统震荡
2. 编码器反馈信号异常或分辨率不足
3. 机械传动间隙过大（联轴器、丝杠、减速机）
4. 负载惯量比过大，动态响应差
5. 电机刚性不足或安装松动

## 三、排查步骤
1. 观察抖动发生时机（运行中还是定位停止时）
2. 检查伺服增益参数设置是否过高
3. 检查编码器信号与接线
4. 检查机械传动间隙
5. 检查电机安装是否牢固、负载惯量比

## 四、维修处理
1. 降低伺服增益参数，消除震荡
2. 更换异常编码器，恢复反馈信号
3. 消除机械传动间隙
4. 调整负载惯量比，必要时增加减速比
5. 加固电机安装，增强刚性

## 五、预防措施
合理设置伺服增益，保持编码器与机械传动良好，控制负载惯量比，避免电机安装松动。
