# 铣床主轴温升过高故障

## 一、故障现象
铣床连续加工后主轴温升过快、温度过高，主轴箱发热，热变形导致加工尺寸不稳定，严重时主轴抱死。

## 二、常见原因
1. 主轴轴承润滑不良、缺油或油脂劣化
2. 主轴轴承预紧力过大或磨损
3. 主轴冷却系统故障
4. 长时间高速重载切削
5. 主轴与轴承配合间隙过小

## 三、排查步骤
1. 用测温仪测量主轴各部位温度，定位热源
2. 检查主轴轴承润滑与油脂状态
3. 检查主轴冷却循环是否正常
4. 查阅切削参数，判断是否长期高速重载
5. 检查轴承预紧与配合间隙

## 四、维修处理
1. 补充或更换轴承润滑油脂
2. 调整轴承预紧力，更换磨损轴承
3. 修复主轴冷却系统
4. 合理调整切削参数
5. 重新调整轴承配合间隙

## 五、预防措施
定期检测主轴温升与润滑，保持冷却系统畅通，合理选择切削参数，避免主轴长期高速重载。
