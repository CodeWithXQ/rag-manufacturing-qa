# 空压机压力不足产气量下降故障

## 一、故障现象
空压机排气压力上不去、达不到设定值，产气量明显下降，用气端压力不足，机组加载时间变长或持续加载。

## 二、常见原因
1. 空气过滤器滤芯堵塞，进气量不足
2. 进气阀伺服气缸、电磁阀异常，进气阀开度受限或卡死
3. 输气管路、控制气路、安全阀、排水阀等存在泄漏
4. 主机转子磨损，内部间隙变大，内泄产气效率下降
5. 实际用气量大于机组产气量，卸载压力设定值过低

## 三、排查步骤
1. 按由简到难顺序，优先检查空气滤芯是否堵塞
2. 检查进气阀组件动作是否灵敏、开度是否正常
3. 开展管路检漏，排查输气管路、控制气路、阀件漏点
4. 观察机组加载状态，判断是否用气量超过产气量
5. 检查最小压力阀、放空阀、压力传感器是否正常

## 四、维修处理
1. 更换堵塞的空气滤芯
2. 拆检进气阀，清理积污，修复卡滞配件
3. 修补管路漏点，更换老化密封管件与泄漏阀件
4. 检修最小压力阀、放空阀，校准压力传感器
5. 正确设定卸载压力，必要时增配机组或储气罐
6. 若外部正常仍压力低，需拆机校准主机转子间隙

## 五、预防措施
定期更换空气滤芯，保持管路密封，监测主机排气量，避免用气量长期超出机组产气能力。
