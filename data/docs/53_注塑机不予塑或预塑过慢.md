# 注塑机不予塑或预塑过慢故障

## 一、故障现象
合模、注射、保压完成后，螺杆不后退或后退极慢，无法完成预塑储料，制品无法连续生产；或预塑时螺杆转动但不下料。

## 二、常见原因
1. 预塑终止行程开关的撞块未拨开，行程开关已闭合
2. 单向节流阀关死，油路不通
3. 料温过低，塑料未充分熔融
4. 预塑电磁阀卡死或不得电
5. 预塑压力设定过低
6. 螺杆内进入异物卡死
7. 背压过高、加料口冷却水不足导致物料"架桥"、缺料、螺杆断裂

## 三、排查步骤
1. 检查预塑终止行程开关与撞块位置，确认开关状态
2. 检查单向节流阀开度，判断油路是否畅通
3. 核对料筒各区温度与背压设定值
4. 观察加料口是否下料顺畅，有无"架桥"现象
5. 拆检预塑电磁阀，手动推动阀芯确认是否卡滞

## 四、维修处理
1. 拨开预塑终止行程开关的撞块
2. 调整单向节流阀开度，调高预塑压力
3. 升高料温至工艺要求
4. 拆卸清洗预塑电磁阀
5. 拆卸螺杆清洗料筒，取出卡滞异物；若螺杆断裂则更换
6. 调低背压，调整加料口冷却水量，取出粘结成块的塑料

## 五、预防措施
保持料筒温度均匀稳定，控制加料口冷却水量，定期检查预塑行程开关与电磁阀动作，避免异物进入料筒。
