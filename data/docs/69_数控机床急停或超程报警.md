# 数控机床急停或超程报警故障

## 一、故障现象
机床运行中突然急停或报超程报警，各轴运动停止，无法复位或复位后再次报警，加工中断。

## 二、常见原因
1. 急停按钮被误按或急停回路接触不良
2. 轴超程，撞到硬限位开关
3. 行程开关（硬限位）损坏或线路虚接
4. 软限位参数设置不当
5. 急停继电器、安全回路故障

## 三、排查步骤
1. 检查急停按钮是否处于按下状态，急停回路是否导通
2. 观察报警轴，检查是否超程撞限位
3. 检查硬限位行程开关及线路是否正常
4. 核对软限位参数设置是否合理
5. 检查急停继电器与安全回路接触情况

## 四、维修处理
1. 复位急停按钮，修复接触不良的急停回路
2. 手动反向移动超程轴，脱离硬限位
3. 更换损坏的行程开关，修复虚接线路
4. 修正软限位参数
5. 更换故障急停继电器，恢复安全回路

## 五、预防措施
规范操作避免误碰急停，合理设置软硬限位，定期检查急停回路与行程开关，防止轴超程撞击。
