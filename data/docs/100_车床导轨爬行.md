# 车床导轨爬行故障

## 一、故障现象
车床拖板在低速进给时出现时快时慢的"爬行"现象，运动不平稳，加工表面粗糙度变差，进给不均匀。

## 二、常见原因
1. 导轨润滑不良，油膜不充分
2. 导轨面磨损、拉伤，接触不均匀
3. 进给丝杠螺母间隙调整不当
4. 拖板镶条调整过紧或过松
5. 液压油混入空气（液压驱动进给时）

## 三、排查步骤
1. 观察爬行发生时的进给速度区间
2. 检查导轨润滑情况，油膜是否充分
3. 检查导轨面有无拉伤、磨损
4. 检查进给丝杠螺母间隙与镶条松紧
5. 检查液压油是否混入空气

## 四、维修处理
1. 改善导轨润滑，保证油膜充分
2. 刮研修复导轨面，恢复接触精度
3. 调整进给丝杠螺母间隙
4. 调整拖板镶条松紧至合适
5. 排除液压系统空气

## 五、预防措施
保持导轨良好润滑，定期检查导轨磨损，规范调整丝杠与镶条，避免低速进给时的爬行现象。
