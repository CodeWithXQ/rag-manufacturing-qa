# 磨床砂轮不平衡振动故障

## 一、故障现象
磨床磨削时砂轮振动、工件表面出现振纹，磨削精度下降，砂轮主轴振动明显，伴随周期性噪音。

## 二、常见原因
1. 砂轮静平衡、动平衡不良
2. 砂轮主轴轴承磨损、间隙过大
3. 砂轮安装法兰不平行、松动
4. 砂轮修整不良，表面不平整
5. 磨削进给量过大、砂轮过硬

## 三、排查步骤
1. 观察工件表面振纹形态，判断振源
2. 检查砂轮平衡情况，重新做平衡
3. 检查砂轮主轴轴承间隙
4. 检查砂轮安装法兰与紧固情况
5. 检查砂轮修整质量与磨削参数

## 四、维修处理
1. 对砂轮做静平衡与动平衡校正
2. 更换磨损的主轴轴承，恢复间隙
3. 校正砂轮安装法兰，重新紧固
4. 重新修整砂轮，恢复表面平整
5. 减小进给量，选用合适硬度的砂轮

## 五、预防措施
砂轮安装前做好平衡，定期检查主轴轴承，规范砂轮修整，控制磨削参数避免过载。
