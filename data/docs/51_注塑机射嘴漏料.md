# 注塑机射嘴漏料故障

## 一、故障现象
注射过程中熔融塑料从射嘴与模具浇口套的球面贴合处溢出，射嘴周围堆积料屑，制品缺料或重量不足，严重时喷溅烫伤操作人员。

## 二、常见原因
1. 射嘴温度过高，熔体粘度下降、流动性过强导致溢料；或温度过低，原料未完全熔融形成硬块堵塞射嘴，迫使熔体从侧缝漏出
2. 射嘴密封圈老化、破损，密封失效
3. 射嘴球面与模具浇口套配合间隙过大，或贴合面粘有焦料、粉尘等杂质
4. 背压设置过高，超过原料适配范围，熔体压力过大从贴合处溢出

## 三、排查步骤
1. 观察漏料位置，判断是球面贴合处漏还是射嘴本体与料筒连接处漏
2. 用测温仪核对射嘴实际温度与设定值是否一致，判断加热圈是否正常工作
3. 检查射嘴球面与浇口套的磨损情况，用红丹粉研配检查贴合面积
4. 核对背压设定值是否在原料工艺卡推荐范围内

## 四、维修处理
1. 根据原料特性重新校准射嘴温度，确保原料完全熔融且粘度适中
2. 更换老化的密封圈或垫片，重新紧固连接螺栓
3. 清理射嘴球面与模具浇口套的杂质，必要时对球面进行研磨修复或更换浇口套
4. 将背压调低至适宜范围

## 五、预防措施
定期检查射嘴球面与浇口套的配合状态，保持贴合面清洁，按原料工艺卡设定射嘴温度与背压，避免超温、超压运行。
