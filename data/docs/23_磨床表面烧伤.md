# 磨床表面烧伤故障

## 一、故障现象
磨削加工表面出现蓝紫色氧化色（烧伤），工件表层硬度下降，产生磨削裂纹，影响表面质量。

## 二、常见原因
1. 磨削进给量过大或砂轮太硬
2. 冷却液流量不足或喷淋不到位
3. 砂轮磨钝未及时修整，切削力增大
4. 工件材料导热性差（如轴承钢、不锈钢）

## 三、排查步骤
1. 检查磨削参数（进给量、砂轮线速度）是否过大
2. 检查冷却液流量与喷嘴位置是否对准磨削区
3. 检查砂轮是否磨钝、堵塞
4. 结合工件材质评估砂轮硬度是否匹配

## 四、维修处理
1. 减小进给量、选用更软的砂轮
2. 增大冷却液流量、调整喷嘴对准磨削点
3. 及时修整砂轮，保持锋利
4. 对难磨材料采用专用砂轮与磨削工艺

## 五、预防措施
合理选择砂轮与磨削参数，保证冷却充分，定期修整砂轮，控制磨削温度。
