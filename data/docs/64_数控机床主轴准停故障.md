# 数控机床主轴准停故障

## 一、故障现象
主轴定向停止（准停）位置不准或无法准停，自动换刀时刀柄无法与主轴准确定位，出现掉刀、撞刀或换刀报警。

## 二、常见原因
1. 主轴准停传感器（磁性开关、编码器）位置偏移或损坏
2. 主轴准停信号线路接触不良
3. 主轴驱动器准停参数设置错误
4. 主轴准停机械定位机构磨损
5. 主轴转速过高导致准停过冲

## 三、排查步骤
1. 观察主轴准停角度偏差方向与大小
2. 检查准停传感器安装位置是否松动偏移
3. 测量准停传感器信号是否正常输出
4. 核对驱动器准停参数与主轴齿数设置
5. 检查机械定位键、定位销磨损情况

## 四、维修处理
1. 重新调整准停传感器位置并紧固
2. 更换损坏的准停传感器，修复信号线路
3. 重新设置驱动器准停参数
4. 更换磨损的机械定位部件
5. 降低准停前主轴转速，减少过冲

## 五、预防措施
定期校验主轴准停精度，检查准停传感器与机械定位机构，保持准停参数正确，避免频繁高速准停冲击。
