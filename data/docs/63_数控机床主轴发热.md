# 数控机床主轴发热故障

## 一、故障现象
主轴连续运行后温升异常，主轴箱或主轴本体烫手，热伸长导致加工精度下降，严重时触发主轴过热报警。

## 二、常见原因
1. 主轴轴承润滑不良，缺油或油脂劣化
2. 主轴轴承预紧力过大或磨损损坏
3. 主轴箱冷却系统故障，循环不畅
4. 主轴长时间高速、重载运行
5. 主轴与轴承配合间隙过小，装配不当

## 三、排查步骤
1. 用红外测温仪测量主轴各部位温度，定位发热源
2. 检查主轴轴承润滑情况，观察油脂状态
3. 检查主轴冷却液循环是否正常
4. 查阅加工参数，判断是否长期高速重载
5. 检查轴承预紧与配合间隙

## 四、维修处理
1. 补充或更换主轴轴承润滑油脂
2. 重新调整轴承预紧力，磨损严重时更换轴承
3. 疏通主轴冷却系统，修复冷却泵或管路
4. 合理调整切削参数，避免长期超负荷
5. 重新装配并调整轴承配合间隙

## 五、预防措施
定期检测主轴温升与润滑状态，保持冷却系统畅通，按工艺合理选择切削参数，避免主轴长期高速重载运行。
