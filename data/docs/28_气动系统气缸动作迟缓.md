# 气动系统气缸动作迟缓故障

## 一、故障现象
气缸伸出/缩回速度变慢、动作无力或走走停停，无法在规定时间内完成动作，影响生产节拍。

## 二、常见原因
1. 气源压力不足
2. 管路或接头泄漏
3. 节流阀开度过小或堵塞
4. 气缸内部密封件磨损内泄

## 三、排查步骤
1. 测量气源压力是否达到规定值
2. 检查管路与接头有无漏气（涂肥皂水检漏）
3. 检查节流阀开度与是否堵塞
4. 断开负载检测气缸空载动作速度

## 四、维修处理
1. 提高气源压力或检修空压机
2. 封堵或更换泄漏的管路、接头
3. 调大或清洗节流阀
4. 更换气缸密封件或整个气缸

## 五、预防措施
定期检漏，保持气源压力稳定，做好气源三联件（过滤/减压/油雾）的排水与维护。
