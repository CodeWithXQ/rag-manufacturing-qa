# 液压缸内泄压力下降故障

## 一、故障现象
液压缸工作压力下降、动作无力，活塞杆停不住（中位漂移），保压时压力缓慢下降。

## 二、常见原因
1. 活塞密封件磨损
2. 缸筒内壁拉伤
3. 活塞杆密封（杆封）损坏
4. 液压锁（液控单向阀）内泄

## 三、排查步骤
1. 保压测试，观察压力下降速度判断内泄
2. 拆检活塞密封件磨损情况
3. 检查缸筒内壁有无拉伤
4. 检查液压锁密封是否失效

## 四、维修处理
1. 更换活塞密封件
2. 修复或更换拉伤的缸筒
3. 更换活塞杆密封
4. 更换或维修液压锁

## 五、预防措施
定期保压测试液压缸内泄，保持油液清洁，避免超载偏载运行。
