# 冷却系统流量不足故障

## 一、故障现象
冷却水流量明显下降，设备冷却效果变差，主轴/模具/工件温度升高，触发温控报警。

## 二、常见原因
1. 冷却水泵叶轮磨损或电机故障
2. 管路结垢、堵塞或阀门未全开
3. 过滤器（Y型过滤器）堵塞
4. 冷却水箱液位过低或吸水管漏气

## 三、排查步骤
1. 检查水泵运行声音与出口压力
2. 检查各阀门开度与管路有无堵塞
3. 拆洗 Y 型过滤器
4. 检查水箱液位与吸水管密封

## 四、维修处理
1. 更换磨损叶轮或检修水泵电机
2. 疏通或更换堵塞管路，全开阀门
3. 清洗过滤器
4. 补足冷却水、修复吸水管密封

## 五、预防措施
定期清洗过滤器与管路，检查水泵工况，保持水箱液位，监测进出水温差。
