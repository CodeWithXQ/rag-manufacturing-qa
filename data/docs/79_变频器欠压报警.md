# 变频器欠压报警故障

## 一、故障现象
变频器运行中报欠压故障（面板显示 LU、LV 等代码），变频器停机保护，直流母线电压低于保护阈值，多发生在重载或电网波动时。

## 二、常见原因
1. 输入电压过低或三相电压不平衡
2. 输入接线不良、输入缺相
3. 运行中掉电或电压瞬时跌落
4. 重负载冲击导致电压跌落
5. 充电接触器损坏、电压检测回路元件不良

## 三、排查步骤
1. 测量输入电源电压是否偏低、是否缺相
2. 检查输入接线端子是否松动
3. 观察欠压是否在重载启动或冲击时发生
4. 检查充电接触器是否正常吸合
5. 检查电压检测回路与欠压检测参数设置

## 四、维修处理
1. 恢复输入电压至正常范围，排除缺相
2. 紧固输入接线端子
3. 减小负载冲击，必要时增大供电容量
4. 更换损坏的充电接触器
5. 检修电压检测回路，调整欠压检测参数

## 五、预防措施
保证供电容量充足、三相平衡，定期检查输入接线，避免与大型设备共用电源导致电压跌落。
