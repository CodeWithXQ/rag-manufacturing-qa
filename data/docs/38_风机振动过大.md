# 风机振动过大故障

## 一、故障现象
风机运行振动值超标，基础与风管抖动，伴随噪声，轴承寿命缩短，严重时地脚螺栓松动。

## 二、常见原因
1. 叶轮不平衡或积灰结垢
2. 轴承磨损、间隙过大
3. 地脚螺栓松动、基础刚度不足
4. 风管共振或安装偏差

## 三、排查步骤
1. 用测振仪检测各测点振动值
2. 检查叶轮积灰、磨损与平衡
3. 检查轴承间隙与地脚螺栓
4. 检查风管连接与共振情况

## 四、维修处理
1. 清理叶轮积灰、重新做动平衡
2. 更换磨损轴承
3. 紧固地脚螺栓、加固基础
4. 调整风管支撑、消除共振

## 五、预防措施
定期清理叶轮与测振，及时更换轴承，保持基础牢固，避免共振工况。
