# 工业机器人轴超载报警故障

## 一、故障现象
机器人运行中某轴报超载/过力矩报警，动作卡顿或停机，机械臂无法正常运动。

## 二、常见原因
1. 负载超过轴额定转矩
2. 减速机卡滞或轴承损坏
3. 伺服电机抱闸未释放
4. 机械臂碰撞或卡阻

## 三、排查步骤
1. 读取报警轴与力矩值，判断是启动还是运行中超载
2. 检查末端负载是否超重
3. 检查减速机与轴承是否卡滞
4. 检查抱闸释放与机械碰撞

## 四、维修处理
1. 降低负载或优化轨迹
2. 检修或更换减速机、轴承
3. 检修抱闸电路与机械
4. 排除碰撞卡阻、重新标定

## 五、预防措施
合理设定负载与轨迹，定期检查减速机与抱闸，避免碰撞超载。
