# 数控机床电气系统故障

## 一、故障现象
机床辅助功能（冷却、润滑、刀库、排屑等）无动作或误动作，接触器、继电器不吸合或频繁跳闸，机床无法正常工作。

## 二、常见原因
1. 接触器、继电器触点烧蚀、线圈损坏
2. 电磁阀、执行元件故障
3. 行程开关、接近开关信号异常
4. 电气线路松动、虚接、短路
5. 保险丝、断路器熔断跳闸

## 三、排查步骤
1. 遵循"先信号、后器件、最后机械"顺序排查
2. 从 PLC 程序相关信号出发，确认控制信号与反馈信号状态
3. 检查接触器、继电器、电磁阀的线圈与触点
4. 检查行程开关、接近开关等信号元件
5. 检查执行元件（电机、液压缸、气缸）及机械结构

## 四、维修处理
1. 更换烧蚀的接触器、继电器触点或损坏的线圈
2. 更换故障电磁阀、行程开关、接近开关
3. 紧固松动的电气接线，排除虚接、短路
4. 更换熔断的保险丝，查明原因后复位断路器
5. 检修执行元件与机械结构

## 五、预防措施
定期检查电气柜内元器件与接线，保持接触器触点清洁，建立电气故障记录，避免潮湿、粉尘导致的电气故障。
