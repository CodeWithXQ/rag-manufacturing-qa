# 焊接机虚焊故障

## 一、故障现象
焊点外观不饱满、焊料未充分熔合，机械强度不足，受外力易开裂脱落，电气接触不良。

## 二、常见原因
1. 焊接电流过小或焊接时间不足
2. 焊接面有氧化层、油污或异物
3. 电极接触不良、压力不足
4. 焊料（锡/焊条）质量差或助焊剂失效

## 三、排查步骤
1. 检查焊接参数（电流、时间、压力）是否匹配工件
2. 检查焊接面清洁度，有无氧化、油污
3. 检查电极（焊头）磨损与接触情况
4. 核对焊料与助焊剂规格是否合适

## 四、维修处理
1. 调整焊接电流、时间、压力至合理值
2. 打磨清洁焊接面，去除氧化与油污
3. 修磨或更换电极，保证良好接触
4. 更换合格焊料与助焊剂

## 五、预防措施
按工艺卡设定焊接参数，焊接前清洁工件，定期修磨电极，做好焊料管理。
