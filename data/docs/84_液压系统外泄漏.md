# 液压系统外泄漏故障

## 一、故障现象
液压系统管路接头、阀件、油缸处渗油漏油，油箱油位持续下降，设备周围出现油渍，系统压力不稳定。

## 二、常见原因
1. 管路接头松动、螺纹损坏
2. 密封圈、O 型圈老化、破损
3. 油缸活塞杆密封磨损、划伤
4. 管件、阀体有裂纹或铸造缺陷
5. 系统压力过高超过密封耐压能力

## 三、排查步骤
1. 观察漏油部位，区分是接头、阀件还是油缸泄漏
2. 用干净的布擦拭泄漏点，观察渗漏速度与来源
3. 检查各接头紧固情况
4. 检查密封圈是否老化、变形、破损
5. 检查油缸活塞杆有无划伤

## 四、维修处理
1. 紧固松动的接头，修复或更换损坏的螺纹
2. 更换老化破损的密封圈、O 型圈
3. 更换油缸活塞杆密封，修复划伤的活塞杆
4. 更换有裂纹的管件、阀体
5. 降低系统压力至合理范围

## 五、预防措施
定期检查接头与密封件，使用合格密封圈，控制系统压力，避免活塞杆划伤和密封过早老化。
