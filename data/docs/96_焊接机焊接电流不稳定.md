# 焊接机焊接电流不稳定故障

## 一、故障现象
焊接过程中电流忽大忽小、波动明显，焊缝成形不良、宽窄不均，焊接质量下降，严重时无法引弧或断弧。

## 二、常见原因
1. 焊接电源故障，输出电压电流波动
2. 焊接电缆接头松动、接触不良
3. 焊丝送丝速度不稳（送丝轮磨损、焊丝打滑）
4. 电网电压波动过大
5. 焊接参数设置不当或焊枪接触不良

## 三、排查步骤
1. 观察焊接电流表，判断波动范围与频率
2. 检查焊接电源输出是否稳定
3. 检查焊接电缆与接头是否松动发热
4. 检查送丝机构，观察送丝是否均匀
5. 测量电网电压波动情况

## 四、维修处理
1. 检修焊接电源，排除输出波动
2. 紧固焊接电缆接头，更换接触不良的接头
3. 更换磨损的送丝轮，调整送丝压紧力
4. 加装稳压电源，改善电网质量
5. 调整焊接参数，修复焊枪接触

## 五、预防措施
定期检查焊接电源与电缆接头，保持送丝机构良好，稳定供电电压，按工艺要求设定焊接参数。
