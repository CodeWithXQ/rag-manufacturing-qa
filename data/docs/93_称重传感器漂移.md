# 称重传感器漂移故障

## 一、故障现象
称重系统零点漂移、示值不稳定，空载读数不为零或缓慢变化，称重结果偏差大，重复性差。

## 二、常见原因
1. 传感器受潮，绝缘下降导致漂移
2. 传感器弹性体疲劳或过载损伤
3. 激励电压不稳定
4. 信号线屏蔽不良，受电磁干扰
5. 传感器安装面不平整，受力不均匀

## 三、排查步骤
1. 观察空载零点是否稳定，有无缓慢漂移
2. 检查传感器与接线盒是否受潮
3. 测量激励电压是否稳定
4. 检查信号线屏蔽与接地情况
5. 检查传感器安装面是否平整、受力是否均匀

## 四、维修处理
1. 对受潮传感器做干燥处理，恢复绝缘
2. 更换过载损伤或疲劳的传感器
3. 稳定激励电压，排除电源波动
4. 修复屏蔽线接地，远离干扰源
5. 调整安装面，保证传感器受力均匀

## 五、预防措施
保持传感器干燥，避免过载冲击，稳定激励电源，信号线做好屏蔽接地，定期校验称重精度。
