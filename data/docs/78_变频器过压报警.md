# 变频器过压报警故障

## 一、故障现象
变频器运行中报过压故障（面板显示 OU、OV 等代码），变频器停机保护，多发生在加速或减速过程中，直流母线电压过高。

## 二、常见原因
1. 输入电源电压过高或电网有浪涌尖峰
2. 加减速时间设置太短，再生能量回馈导致直流母线电压升高
3. 负载惯性大，减速时能量回馈制动不足
4. 电机对地漏电或动力线绝缘损坏
5. 对旋转中的电机再次启动（飞车启动）

## 三、排查步骤
1. 测量输入电源电压是否异常偏高
2. 观察过压发生时机（启动、加速、定速、减速），判断原因
3. 检查加减速时间设定是否过短
4. 检查电机及动力线对地绝缘
5. 确认是否有对旋转中电机再启动的情况

## 四、维修处理
1. 检查输入电源，必要时加装输入交流电抗器
2. 延长加速/减速时间至合适值
3. 加装制动单元、制动电阻，消耗回馈能量
4. 修复电机对地漏电，更换绝缘损坏的动力线
5. 避免对旋转中电机直接再启动

## 五、预防措施
合理设置加减速时间，大惯量负载加装制动单元，监测电网电压，定期检查电机与动力线绝缘。
