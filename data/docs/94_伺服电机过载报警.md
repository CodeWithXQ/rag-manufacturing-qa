# 伺服电机过载报警故障

## 一、故障现象
伺服电机运行中报过载报警，驱动器显示过载故障，电机停止或降速，多发生在启动、加速或重载运行时。

## 二、常见原因
1. 负载过大或机械卡滞，超过电机额定转矩
2. 加减速时间设置过短，冲击电流过大
3. 伺服电机与驱动器容量不匹配
4. 电机轴承损坏、机械摩擦阻力增大
5. 电机接线错误或绕组故障

## 三、排查步骤
1. 观察过载发生时机（启动、加速、匀速、减速）
2. 检查负载与机械部分有无卡滞
3. 核对加减速时间参数设置
4. 核对电机与驱动器容量是否匹配
5. 检查电机轴承与绕组

## 四、维修处理
1. 减小负载，排除机械卡滞
2. 适当延长加减速时间
3. 更换匹配容量的伺服电机或驱动器
4. 更换损坏的轴承，减小摩擦
5. 纠正接线，修复绕组故障

## 五、预防措施
控制负载在额定范围内，合理设置加减速参数，保持机械部分润滑良好，避免伺服电机长期过载运行。
