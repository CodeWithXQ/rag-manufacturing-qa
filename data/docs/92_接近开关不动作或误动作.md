# 接近开关不动作或误动作故障

## 一、故障现象
接近开关检测不到目标（不动作）或没有目标时误动作，检测信号不稳定、时有时无，导致设备动作错乱。

## 二、常见原因
1. 接近开关检测距离设置不当，目标超出感应范围
2. 接近开关损坏或供电异常
3. 检测目标材质、尺寸不符合开关要求（如电感式需金属）
4. 周围电磁干扰导致误动作
5. 安装松动，开关位置偏移

## 三、排查步骤
1. 检查接近开关检测距离，用标准目标测试动作
2. 测量接近开关供电电压是否正常
3. 核对检测目标材质与开关类型是否匹配
4. 观察信号是否受干扰，检查周围有无强磁场、变频器
5. 检查接近开关安装是否松动偏移

## 四、维修处理
1. 调整检测距离至开关额定范围内
2. 更换损坏的接近开关，恢复供电
3. 更换匹配目标材质的开关类型
4. 加装屏蔽、远离干扰源，或更换抗干扰型号
5. 重新固定并校准接近开关位置

## 五、预防措施
按目标材质选择开关类型，安装时留好检测距离余量，远离电磁干扰源，定期检查安装紧固。
