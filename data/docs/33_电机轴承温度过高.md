# 电机轴承温度过高故障

## 一、故障现象
电机轴承部位温度明显偏高，油脂流失变干，轴承运行噪声增大，严重时轴承抱死。

## 二、常见原因
1. 润滑脂加注过多或过少
2. 轴承安装配合过紧或联轴器不对中
3. 轴承本身磨损、游隙过大
4. 负载过重或轴向力过大

## 三、排查步骤
1. 测量轴承端盖温度并与环境对比
2. 检查润滑脂加注量与状态
3. 用振动仪检测轴承部位振动值
4. 检查联轴器对中情况

## 四、维修处理
1. 调整润滑脂加注量
2. 重新校正联轴器同轴度
3. 更换磨损轴承
4. 降低负载或消除异常轴向力

## 五、预防措施
按周期加注适量润滑脂，定期检测轴承振动与温度，保证联轴器对中。
